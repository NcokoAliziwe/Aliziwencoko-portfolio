# User Stories and Tasks — Shezz-App

## 1. Registration
**Story:** As a customer, I want to create an account and sign in so that I can access salon features.

**Tasks:**
- [ ] Create registration form
- [ ] implement sign-in
- [ ] validate inputs
- [ ] test error states.

## 2. Catalogue
**Story:** As a customer, I want to browse salon services so that I can choose an appointment.

**Tasks:**
- [ ] Display services
- [ ] show descriptions and pricing where available
- [ ] test layout.

## 3. Booking
**Story:** As a customer, I want to request an appointment so that I can reserve a salon service.

**Tasks:**
- [ ] Create booking UI
- [ ] select service/date/time
- [ ] validate submission
- [ ] test flow.

## 4. Make an Offer
**Story:** As a customer, I want to upload a hairstyle reference and propose a price so that I can negotiate with a stylist.

**Tasks:**
- [ ] Add image upload
- [ ] price proposal
- [ ] response states
- [ ] test offer submission.

## 5. Loyalty Rewards
**Story:** As a returning customer, I want my visits counted so that I can receive a reward.

**Tasks:**
- [ ] Track eligible visits
- [ ] show reward progress
- [ ] display redemption mechanism.

## 6. Download and Deployment
**Story:** As a customer, I want to install or access the app on my phone so that I can use it conveniently.

**Tasks:**
- [ ] Prepare deployment
- [ ] add install/download capability
- [ ] test on devices.


> Checkboxes are evidence placeholders: tick only after verifying completion.

## Reflection
I learned to translate customer needs into specific development tasks. I would improve future stories by adding acceptance criteria and attaching screenshots or commits.
